# 🗺️ Руководство пользователя / User Guide
## 1. Сцена входа (Авторизация и Управление Проектами)
Начальный экран приложения отвечает за аутентификацию пользователя и инициализацию рабочего пространства.

* Авторизация: войти в существующий аккаунт или зарегистрировать новый (клиентский).
* Разграничение прав: доступные окна и внутренние настройки зависят от роли пользователя.
* Навигация: доступно свободное переключение между активными окнами интерфейса.
* Условие перехода: для открытия редактора необходимо создать новый чертеж в Меню проектов.

------------------------------
## 2. Сцена чертежа (2D-Планировка)
Инструмент для создания и точной настройки геометрии помещения.
## 🎮 Управление элементами чертежа

* Зажатие ЛКМ на точке — перемещение точки по рабочему полю.
* Клик ЛКМ по точке — удаление выбранной точки.
* Клик ЛКМ по линии — создание новой точки на ребре (сегменте стены).

## ⚙️ Дополнительный функционал

* Слои: настройка видимости и отображения различных слоев чертежа.
* Сохранение: кнопка сохранения текущего прогресса проекта.
* Условие перехода: переход на следующий этап доступен только после сохранения чертежа.

------------------------------
## 3. Сцена пространства (3D-Расстановка)
Интерфейс для интерактивного размещения мебели в трехмерном пространстве.
## 🛋️ Выбор и визуализация

* Выбор элементов мебели осуществляется через встроенный каталог.
* При выборе появляется 3D-модель с голограммой-подсказкой (индикатор возможности установки).

## 🕹️ Схема управления

| Действие | Управление камерой | Управление моделью мебели |
|---|---|---|
| Перемещение | Клавиши W, A, S, D | Движение курсора мыши (позиция) |
| Вращение / Установка | Зажатие ПКМ на экране + движение мыши | Клик ПКМ (разместить модель) |
| Удаление | — | Клик ЛКМ по модели мебели |

## 🛒 Завершение работы

* Сохранение: верхнее меню позволяет полностью сохранить текущую расстановку.
* Заказ: кнопка быстрого оформления заказа на всю добавленную в проект мебель.
